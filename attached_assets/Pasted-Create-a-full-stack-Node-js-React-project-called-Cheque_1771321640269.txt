Create a full-stack Node.js + React project called "ChequeClear India" optimized for Replit.

Use Indian banking context and Indian Rupee (₹).

----------------------------------------
1) Backend (Node.js + Express + MongoDB Atlas)
----------------------------------------

Implement:

A) Indian Bank Support
- Support banks like:
    HDFC Bank
    State Bank of India (SBI)
    ICICI Bank
    Axis Bank
- Each user must have:
    name
    bankName
    accountNumber
    IFSC code
    balance (in INR ₹)

B) Cheque Processing Logic

When cheque is submitted:

1. Capture:
   - Payer bank
   - Payee bank
   - Amount (₹)
   - Cheque number
   - Image upload
   - Date

2. Store:
   - Payer balance BEFORE transaction
   - Payee balance BEFORE transaction

3. AI Verification (Simulated but structured):
Return:
{
  signatureScore: number,
  tamperStatus: "No Tampering" | "Suspicious Alteration",
  duplicateCheck: "Unique" | "Duplicate Found",
  riskLevel: "Low" | "Medium" | "High",
  explanation: string
}

4. Clearance Rules:

IF:
- AI riskLevel = High
→ Status = CANCELLED
→ Explanation must clearly state reason:
   "Cheque cancelled due to high fraud risk detected in signature analysis."

IF:
- Balance < Amount
→ Status = BOUNCED
→ Explanation:
   "Cheque bounced due to insufficient funds in payer's account."

IF:
- AI riskLevel Low/Medium AND sufficient balance
→ Status = CLEARED
→ Deduct amount from payer
→ Add amount to payee

5. After transaction, store:
   - Payer balance AFTER
   - Payee balance AFTER
